05AI 검색(AEO) 장치

  1. 표·숫자는 전부 HTML 글자 (면적표 29행, 배후수요, 분양가 예시) — 이미지 속 글자 0
  2. 페이지마다 FAQ 2~4개 + FAQPage 구조화 데이터 (총 26문항)
  3. LocalBusiness·BreadcrumbList·ItemList(29호실)·NewsArticle 구조화 데이터, sitemap.xml, llms.txt
  4. "방학역 상권", "도봉역 상권", "상가 투자", "수익형 부동산" 질문에 답하는 문장을 해당 페이지에 배치
  5. 시안 단계는 noindex + robots 차단 → 정식 오픈 때 해제하고 서치어드바이저·서치콘솔 등록
